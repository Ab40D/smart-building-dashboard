# Contributing / المساهمة

This is a personal portfolio — you (Abdelkhalek) are the only contributor. The
maintenance workflow is:

1. Edit content in `src/data/*.ts`
2. Run `npm run dev` to preview
3. Run `npm run build` to make sure it still compiles
4. Commit and push

See [`RESUME.md`](./RESUME.md) for the full bilingual (Arabic + English) guide
on every file and how to update each section.
